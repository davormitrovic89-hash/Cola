# Beispielseite "Muster AG"

Diese Seite ist **frei erfunden**. Sie existiert nur als Testmaterial für
`tools/audit.mjs` und bildet nach, was einer Firmenseite aus den frühen
2010er-Jahren typischerweise fehlt:

- kein Viewport-Meta-Tag (also keine Handy-Darstellung)
- festes 980-px-Layout in einer Tabelle
- Kamerafotos in Originalgrösse, unskaliert eingebunden
- jQuery 1.7.2 (2012)
- keine Alt-Texte, keine Meta-Description, kein Favicon
- Verweise auf Dateien, die es nicht mehr gibt
- Copyright-Jahr 2011

Adresse, Telefonnummer und Firmenname sind Platzhalter (`.example`-Domain).
Keine Ähnlichkeit mit einer realen Firma beabsichtigt.

Bilder erzeugen: `node tools/beispiel/erzeuge-bilder.mjs`
